# MASTER PLAN — Playlist Long Video Maker v0.3

## 목적

CapCut은 1SET 완성에만 사용하고, 장시간 반복/연결은 PLVM이 담당한다.

```text
CapCut
  → 완성 SET MP4 (자막/이미지/파형/음원/구독요소 포함)
  → PLVM 회차 선택
  → 최대 5개 대기열
  → FFmpeg stream copy 순차 실행
  → 최종 MP4 검증
```

## 절대 원칙

1. 기본/실전 제작에서 영상·오디오 재인코딩 금지.
2. FFmpeg `-c copy`를 사용한다.
3. 서로 호환되지 않는 다중 SET은 자동 변환하지 않고 차단한다.
4. 회차 모드는 완전한 SET 순환까지만 출력하여 중간 컷을 만들지 않는다.
5. 대기열은 최대 5개, 동시에 실행하는 FFmpeg는 항상 1개다.
6. 실패/중지 시 `.part.mp4`와 임시 폴더를 정리한다.
7. 성공 후 ffprobe로 길이와 스트림 속성을 검증한다.

## v0.3 범위

- 단일/다중 SET
- 회차 기준 1~100회
- 시간 기준 최대 12시간
- 최대 5개 자동 대기열
- 실패해도 다음 작업 계속 옵션
- 출력명 자동 생성
- 중복 파일명 자동 회피
- 디스크 여유 공간 검사
- 진행률/중지/로그
- stream-copy 검증
