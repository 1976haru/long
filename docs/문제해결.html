오류 창 읽는 법

오류 창은 항상 두 부분으로 나옵니다.

  무슨 문제가 생겼나요?  예: YouTube 채널이 다릅니다.
  무엇을 하면 되나요?    예: 예약 업로드에서 올바른 채널을 다시 선택하세요.  채널 다시 선택

기술적인 내용(HTTP 번호 등)은 [자세히 보기]를 눌렀을 때만 보입니다.

⑩ 문제 해결

• Google 연결 파일이 없습니다 → Google 계정 처음 연결하기 → 처음이에요 - 만드는 방법 보기 (도움말 '⑦ Google 연결 파일 만들기').
• 선택한 재생목록이 현재 YouTube 채널의 것이 아닙니다 → 재생목록을 다시 고르세요 (새로고침).
• 재생목록 추가 실패 → 영상은 그대로 있습니다. 재생목록만 다시 추가을 누르세요.
• FFmpeg를 찾지 못했습니다 → 메인의 [FFmpeg 설정]에서 ffmpeg.exe를 선택하세요 (같은 폴더에 ffprobe.exe 필요).
• Google 연결이 끊겼습니다 → YouTube 채널 관리에서 그 채널의 Google 계정 연결을 다시 누르세요.
• Google 연결 권한이 부족합니다 (댓글) → 그 채널을 '댓글 기능 권한도 함께 요청'을 켠 채 다시 연결하세요.
• YouTube 채널이 다릅니다 → 예약 업로드에서 올바른 채널을 고르거나, 그 채널로 다시 연결하세요.
• 예약 시간이 지났습니다 → 지금보다 5분 이상 뒤로 다시 고르세요.
• 오늘 사용량 한도 → 내일 다시 시도하세요. 작업은 그대로 남아 있습니다.
• 어디가 문제인지 모르겠으면 메인의 ⚙ 설정 점검을 누르세요.
• 도움을 요청할 때는 진단 정보 복사를 눌러 복사한 내용을 붙여넣으세요 (비밀값은 들어가지 않습니다).

⑦ Google 연결 파일 만들기

이 파일은 YouTube Playlist Studio가 내 YouTube 채널에 업로드할 수 있도록
Google에게 허락받기 위한 연결 파일입니다.
Google 비밀번호가 들어 있는 파일은 아닙니다.

하지만 다른 사람에게 보내거나 GitHub 같은 인터넷에 올리지 마세요.

처음 연결할 때 Google 계정 처음 연결하기 → 처음이에요 - 만드는 방법 보기을 누르면 아래 순서가 담긴 도우미 창이 열립니다.
도우미 창의 Google Cloud 열기로 브라우저를 열고, 창을 옆에 둔 채 따라 하세요. (설정 순서 복사로 순서를 복사할 수 있습니다.)

STEP 1. Google Cloud 열기
Google 계정으로 로그인하고 프로젝트를 하나 만들거나 기존 프로젝트를 선택하세요.

STEP 2. YouTube Data API 사용
'API 및 서비스'에서 YouTube Data API v3를 찾아 [사용] 또는 [Enable]을 누르세요.

STEP 3. Google 앱 설정
Google Auth Platform(또는 OAuth 동의 화면)에서 앱 이름과 지원 이메일을 정하세요.
혼자 쓰는 테스트라면 'Testing'(테스트) 상태로 둬도 됩니다. 이때는 사용할 Google 계정을 'Test users'(테스트 사용자)에 추가해야 할 수 있습니다.

STEP 4. OAuth Client 만들기
Clients → Create client(클라이언트 만들기) → Application type: Desktop app(데스크톱 앱)
이름 예: YouTube Playlist Studio → 만들기

STEP 5. JSON 다운로드
만든 Desktop client의 JSON 파일을 내려받으세요 (보통 '다운로드' 폴더에 저장됩니다).

STEP 6. 프로그램으로 돌아오기
이 프로그램에서 다운로드한 연결 파일 선택을 누르고 방금 받은 파일을 고르세요.

이미 파일이 있으면 있어요 - 파일 선택을 누르세요.

⑨ 자주 묻는 질문

Q. 창을 닫으면 업로드가 멈추나요?
A. 예약 업로드 창을 닫아도 프로그램이 켜져 있으면 계속됩니다. 프로그램 자체를 종료하면 멈추고, 다음에 ▶ 예약 업로드 시작을 누르면 받은 곳부터 이어서 올립니다.

Q. 컴퓨터를 꺼도 예약 공개가 되나요?
A. 네. 업로드가 끝난 영상은 YouTube가 정한 시간에 공개합니다. 단, 첫 댓글과 새 댓글 확인은 프로그램이 켜져 있어야 합니다.

Q. 한국 영상이 일본 채널에 올라갈 수 있나요?
A. 업로드 직전마다 실제 채널을 확인하고, 다르면 업로드하지 않습니다.

Q. 썸네일이 없으면요?
A. 썸네일 없이도 업로드됩니다. 나중에 YouTube Studio에서 바꿀 수 있습니다.

Q. 영상이 비공개로만 올라가요.
A. 'Google 설정 확인 필요'로 표시됩니다. 검수되지 않은 Google 프로젝트는 비공개로만 올릴 수 있습니다. 같은 영상을 다시 올리지 마세요.
