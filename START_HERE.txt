Playlist Long Video Maker v0.3
==============================

가장 쉬운 사용법
1) RUN_WINDOWS.bat 실행
2) [＋ 영상 추가] → CapCut에서 완성한 SET MP4 선택
3) [회차 기준] 권장 → 5/10/15/20회 또는 직접 회차 입력
4) [＋ 현재 설정을 대기열에 추가]
5) 다음 작업도 반복해서 추가 (최대 5개)
6) [▶ 대기열 자동 시작]

중요
- 회차 기준은 SET 중간에서 절대 자르지 않습니다.
- 여러 SET을 넣으면 목록 전체 순서 1바퀴가 1회차입니다.
- v0.3은 재인코딩하지 않습니다(-c copy).
- 여러 SET 규격이 다르면 화질 보존을 위해 작업을 막습니다.
- 대기열 5개를 등록해도 FFmpeg는 1개씩 순차 실행합니다.
