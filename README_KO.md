# Playlist Long Video Maker v0.3

CapCut에서 **자막·이미지·파형·음원·구독/좋아요 요소까지 완성한 SET MP4**를 장시간 플레이리스트로 자동 조립하는 Windows 도구입니다.

## v0.3 핵심

- **회차 기준 반복** 추가: 49분 26초짜리 SET을 10회 선택하면 정확히 SET 10개를 이어 붙여 약 `08:14:20`으로 끝납니다. 마지막 SET을 중간에서 자르지 않습니다.
- 시간 기준도 유지: 3/5/8/10/11시간 또는 직접 입력. 이 모드는 목표시간에서 끝나므로 마지막 SET이 중간에서 끊길 수 있습니다.
- **자동 대기열 최대 5개**: 서로 다른 SET 작업을 등록하고 순서대로 자동 제작합니다.
- **저메모리 설계**: 영상 프레임을 Python으로 읽지 않고, FFmpeg 프로세스 1개만 순차 실행합니다.
- **원본 화질 보존 전용**: `-c copy` stream copy만 사용하며 영상/오디오를 재인코딩하지 않습니다.
- 다중 SET은 코덱/해상도/FPS/픽셀포맷/오디오 샘플레이트/채널이 호환되는지 엄격 검사합니다. 다르면 재인코딩으로 억지 변환하지 않고 작업을 막습니다.
- 완성 후 ffprobe로 길이와 주요 스트림 속성을 다시 검사합니다.
- `.part.mp4` + 임시 폴더를 사용하고 성공 후 최종 파일명으로 교체합니다. 중지/실패 시 임시파일을 정리합니다.

## 가장 쉬운 사용법

1. `RUN_WINDOWS.bat` 실행
2. `＋ 영상 추가`에서 CapCut 완성 SET MP4 선택
3. **회차 기준**에서 `5회 / 10회 / 15회 / 20회` 또는 직접 회차 입력
4. 저장 위치 확인
5. `＋ 현재 설정을 대기열에 추가`
6. 다음 SET도 같은 방식으로 추가 (최대 5개)
7. `▶ 대기열 자동 시작`

### 회차 기준 예

- 원본 SET: `00:49:26`
- 10회: `08:14:20`
- 15회: `12:21:30`

회차 모드는 **SET 경계에서만 종료**하므로 자막/음악/영상이 중간에서 끊기지 않습니다.

## 화질 보존 원칙

v0.3은 안전모드 재인코딩을 제거했습니다. 프로그램의 핵심 FFmpeg 옵션은 다음과 같습니다.

```text
-c copy
```

즉 H.264 영상을 H.264로 다시 압축하는 것이 아니라, 기존 영상/오디오 패킷을 새 MP4 컨테이너에 연결합니다. 다중 SET의 출력 규격이 서로 다르면 프로그램이 작업을 차단하고 **CapCut에서 동일한 출력 설정으로 다시 내보내도록 안내**합니다.

## 메모리 사용 원칙

- Python은 영상 프레임을 디코딩하지 않습니다.
- FFmpeg 작업은 대기열에서 **항상 1개씩 순차 실행**합니다.
- 대기열 5개를 등록해도 5개 FFmpeg를 동시에 실행하지 않습니다.
- 외부 영상 처리 라이브러리(PyAV 등)를 추가하지 않아 메모리 사용을 낮춥니다.

## FFmpeg

`ffmpeg.exe`와 `ffprobe.exe`가 필요합니다.

- PATH에 있으면 자동 인식
- 프로젝트 `bin` 폴더에 넣어도 됨
- 또는 프로그램의 `FFmpeg 설정`에서 기존 `ffmpeg.exe`를 한 번 지정

## 테스트

```bat
py -3 -m pip install pytest
py -3 -m pytest -q
```

현재 핵심/FFmpeg 통합 테스트는 회차 반복과 stream-copy 스트림 유지까지 검사합니다.
