# YouTube Playlist Studio (Playlist Long Video Maker v0.3)

> 프로그램 이름을 **YouTube Playlist Studio**로 통일합니다. EXE 파일 이름과 설정 폴더(`%APPDATA%\PlaylistLongVideoMaker`)는 기존 그대로입니다.

CapCut에서 **자막·이미지·파형·음원·구독/좋아요 요소까지 완성한 SET MP4**를 장시간 플레이리스트로 자동 조립하는 Windows 도구입니다.

## v0.3 핵심

- **회차 기준 반복**: 49분 26초짜리 SET을 10회 선택하면 SET 10개를 온전히 이어 약 `08:14:20`으로 끝납니다. 마지막 SET을 중간에서 자르지 않습니다.
- 여러 SET을 넣으면 **선택한 SET 전체 순서 1바퀴가 1회차**입니다.
- 시간 기준도 유지: 3/5/8/10/11시간 또는 직접 입력. 이 모드는 목표시간에서 끝나므로 마지막 SET이 중간에서 끊길 수 있습니다.
- **자동 대기열 최대 5개**: 서로 다른 작업을 등록하고 순서대로 자동 제작합니다.
- **저메모리 설계**: Python이 영상 프레임을 읽지 않고 FFmpeg 프로세스도 항상 1개만 실행합니다.
- **원본 화질·음질 보존**: `-c copy` stream copy만 사용하며 영상/오디오를 재인코딩하지 않습니다.
- 다중 SET 규격이 다르면 자동 변환하지 않고 작업을 막습니다.
- 완성 후 ffprobe로 재생시간과 주요 스트림 속성을 다시 검사합니다.
- `.part.mp4`와 임시 폴더를 사용해 실패/중지 시 불완전 파일을 정리합니다.
- 장시간 대기열 동안 Windows 절전 방지 옵션을 제공합니다.
- 대기열을 자동 저장해 프로그램 재실행 시 복구합니다.

## v0.4 개발 중 — 24H LIVE (단일 MP4 / 여러 MP4 Playlist)

상단 **② 실시간 스트리밍** 카드 → **24H Playlist LIVE Studio** 창에서 완성 MP4 1개 또는 여러 개(Playlist, 순서대로 반복)를 YouTube LIVE로 무한 반복 송출합니다.

1. `영상 선택` → 자동으로 **LIVE READY** 검사 (아니면 `LIVE READY 파일 만들기`로 PC에서 한 번만 변환)
2. 실행 위치: **무료 Cloud (권장, PC를 꺼도 방송 계속)** 또는 **내 PC**
3. 무료 Cloud는 처음 한 번 `처음 설정 도우미` (Oracle Always Free 서버 연결 → 자동 준비)
4. YouTube Live Control Room의 Stream Key 입력 (필요하면 `이 PC에 안전하게 기억`)
5. `▶ 24H LIVE 시작` → 상태 확인 → `■ LIVE 종료`

- LIVE READY 파일은 재인코딩 없이 그대로 송출합니다 (**DIRECT COPY**: CPU/RAM 매우 낮음).
- 이 프로그램은 **유료 Cloud 자원을 자동 생성하지 않습니다.** 무료 Cloud를 쓸 수 없으면 `내 PC에서 LIVE`를 사용하세요. 자세한 내용: `docs/FREE_CLOUD.md`

- 처음 테스트는 YouTube Live Control Room에서 **비공개/일부공개** 스트림으로 확인하세요.
- 기존 장시간 MP4 제작 기능과 사용법은 그대로입니다. LIVE는 별도 모듈(`app/live_*.py`)입니다.
- FFmpeg는 계속 동시에 1개만 실행됩니다: 제작 중에는 LIVE 불가, LIVE 중에는 제작 불가.
- 끊기면 5→10→30→60초 간격으로 자동 재접속, 종료 시 FFmpeg를 정상 종료합니다.
- Cloud LIVE 중 PC 프로그램을 닫으면 기본은 **PC만 종료** (Cloud 방송은 계속).
- **여러 영상 Playlist**: LIVE READY MP4 2~20개를 A→B→C→A… 순서로 재인코딩 없이 반복합니다. 모든 영상의 해상도/FPS/오디오가 같아야 합니다.
- **보관 안전 모드** (선택): YouTube는 12시간을 넘는 LIVE를 보관하지 못할 수 있어, 11시간 50분에서 송출을 안전 종료하고 다음 세션을 기다립니다. 11:50은 YouTube 공식 숫자가 아니라 이 프로그램의 안전 여유값입니다.
- **YouTube 자동 교체** (개발 중, 실제 YouTube 미검증): YouTube API로 연결하면 11시간 50분마다 새 방송으로 자동 교체하고 송출은 계속합니다. Google OAuth 앱이 Testing 상태면 연결이 7일 후 만료될 수 있습니다. 이번 버전은 PC 프로그램이 켜져 있어야 교체됩니다. 자세한 내용: `docs/YOUTUBE_ROLLOVER.md`
- Stream Key는 로그/설정 파일에 남기지 않으며, 기억 옵션은 Windows DPAPI 암호화 파일로만 저장합니다. 자세한 내용: `docs/LIVE_ARCHITECTURE.md`
- **예약 LIVE** (② 카드의 `예약 LIVE`, 실제 YouTube 미검증): 한 번/매일/평일/매주/요일 선택 규칙으로 앞으로 7일·최대 7개 방송을 미리 예약하고, `저장된 규칙 부족분 보충`으로 다음 회차를 이어서 만듭니다.

## 3-in-1 화면 — ① 영상 늘리기 · ② 실시간 스트리밍 · ③ 예약 업로드

메인 창 상단의 큰 카드 3개로 기능을 고릅니다. **①은 지금 메인 화면 그대로**(SET → 회차 → 대기열 → 자동 시작)이고, ②③은 별도 창이 열립니다.

**③ 예약 업로드** (개발 중, 실제 YouTube 미검증) — 한국·일본 등 여러 YouTube 채널에 완성 영상을 예약 업로드합니다.

1. `YouTube 채널 관리`에서 채널별 별칭(예: 🇰🇷 한국 시니어, 🇯🇵 CHILI LAB)·언어·시간대를 등록하고 채널마다 Google 계정을 연결
2. **① 채널** 선택 (그 채널의 마지막/기본 템플릿이 자동 적용) → **② 영상** (`영상 선택` 또는 `폴더 한꺼번에 추가`) → **③ 예약** (첫 날짜·시각·간격, **채널 시간대 기준**)
3. `▶ 미리보기 후 대기열에 추가` → 채널(실제 YouTube 채널 이름 확인)·영상 수·썸네일 수·예약 시각·오류/경고 확인 → `N개 대기열에 추가` (최대 100개)
4. `▶ 예약 업로드 시작` → 1개씩 순차 업로드 (창을 닫아도 계속, 중지/재실행 후 받은 위치부터 이어 올리기)

- **폴더 한꺼번에 추가**: 폴더 안 MP4를 이름순(001, 002, … 010)으로 추가합니다. 하위 폴더는 기본으로 보지 않습니다. 파일은 옮기거나 지우거나 이름을 바꾸지 않습니다. `최근 폴더 다시 불러오기`로 마지막 폴더를 다시 읽습니다.
- **썸네일 자동 매칭**: `001.mp4` ↔ `001.jpg`/`001.jpeg`/`001.png`, 없으면 `001_thumbnail.*`, 그래도 없으면 템플릿의 썸네일 방식(고정 1개 / 폴더에서 순서대로). 후보가 2개 이상이면 고르지 않고 `후보 N개 ⚠`로 표시합니다. 썸네일이 없어도 업로드는 됩니다.
- **여러 영상 예약**: 매일 / 평일 / 2일마다 / 매주 / N일마다. 빠른 버튼: 오늘·내일, 07:00·09:00·18:00·19:00·21:00 (직접 입력도 가능).
- **상세 설정(▼)**: 제목·설명·태그·시리즈·썸네일 방식·카테고리·언어·아동용·공개 상태. 채널별 템플릿으로 저장합니다. 변수: `{date} {yyyy} {mm} {dd} {weekday} {channel} {series} {episode} {n} {filename}` (`{episode}`는 파일 이름의 마지막 숫자, 없으면 `회차 지정`으로 입력).
- 채널을 바꾸면 그 채널 템플릿으로 다시 채웁니다 (이전 채널의 설명/태그가 남지 않음).
- 이 PC에서 LIVE 송출 중이면 업로드 시작 전에 `잠시 기다리기 (권장)` / `그래도 업로드`를 묻습니다 (Cloud LIVE는 묻지 않음).
- 업로드 예상 시간은 선택한 참고 속도(10/50/100 Mbps)로 계산한 **참고값**이며 보장 시간이 아닙니다. 화면 아래 API 사용량도 이 프로그램이 호출한 것만 센 참고값입니다.
- 채널 관리의 `복제`는 언어/시간대/카테고리/공개/아동용/템플릿만 복제하고, 채널 연결(OAuth JSON·token·채널 ID)은 복제하지 않습니다.

**💬 댓글 관리** (개발 중, 실제 YouTube 미검증) — 메인 상단 / ③ 예약 업로드 창의 `💬 댓글 관리`

- **첫 댓글 자동등록**: 상세 설정의 `공개 후 첫 댓글 자동등록`. 예약 영상은 공개 전(비공개)에는 댓글을 달 수 없어서, 공개 시각 2분 전부터 확인하고 **공개된 뒤 약 60초 후** 첫 댓글을 답니다. 즉시 공개/일부공개 영상은 처리 후 바로, 예약 없는 비공개 영상은 공개로 바꿀 때까지 기다립니다 (계속 다시 시도하지 않음). 이미 단 첫 댓글은 다시 쓰지 않습니다.
- **프로그램이 꺼져 있으면 댓글을 달 수 없습니다.** 다시 켜면 밀린 첫 댓글을 확인해 등록합니다 (작업은 저장되어 사라지지 않음).
- **새 댓글 확인**: 채널마다 채널 전체 댓글을 한 번에 조회합니다 (영상마다 조회하지 않음). 프로그램이 켜져 있을 때 10분마다 + `지금 새 댓글 확인`.
- **자동답글**: 기본은 `검토 후 답글`. `자동답글 (안전형)`을 직접 켜면 감사·응원 같은 짧은 댓글에만 등록한 문구(채널별 5개 이상 권장)로 답합니다. 질문(?), 링크, 긴 댓글, 제외 키워드, 보류 댓글, 내 댓글, 이미 답글 있는 댓글(YouTube Studio 직접 답글 포함)은 `검토 필요`로 남깁니다. 채널당 24시간 최대 10/20/30개, 답글 사이 60초 이상, 같은 문장 연속 사용 안 함. 구독/좋아요 요청 같은 홍보 문구는 기본 문구에 없습니다.
- 외부 AI는 쓰지 않습니다. API 사용량은 이 프로그램이 호출한 것만 센 참고값입니다.
- 댓글 권한이 부족하다는 응답을 받으면 `댓글 기능 사용을 위해 이 채널의 Google 연결을 다시 승인하세요.`라고 안내합니다. 그 채널을 다시 연결할 때만 댓글 권한(youtube.force-ssl)을 함께 요청합니다. 기존 연결을 강제로 다시 승인시키지 않습니다.

- ①에서 제작이 끝난 작업을 선택하고 `③ 예약 업로드로 보내기`를 누르면 그 영상이 바로 입력됩니다.
- 업로드 직전마다 실제 채널 ID를 다시 확인하고, 다르면 **차단**합니다 (한국 영상이 일본 채널에 올라가는 사고 방지).
- 연결 정보(token)는 채널마다 따로 Windows DPAPI 암호화 파일에 저장되고, 업로드 세션 주소도 암호화해서만 저장합니다.
- 썸네일만 실패하면 영상은 지우지 않고 `다시 시도`로 썸네일만 다시 올립니다. 검수 안 된 Google API 프로젝트라 비공개로 고정되면 `확인 필요 (API 제한)`으로 멈추고 다시 올리지 않습니다.

## 가장 쉬운 사용법

1. `RUN_WINDOWS.bat` 실행
2. `＋ 영상 추가`에서 CapCut 완성 SET MP4 선택
3. **회차 기준**에서 `5회 / 10회 / 15회 / 20회` 또는 직접 회차 입력
4. 저장 위치 확인
5. `＋ 현재 설정을 대기열에 추가`
6. 다음 작업도 같은 방식으로 추가 (최대 5개)
7. `▶ 대기열 자동 시작`

### 회차 기준 예

- 원본 SET: `00:49:26`
- 10회: `08:14:20`
- 15회: `12:21:30`

회차 모드는 **SET 경계에서만 종료**하므로 자막/음악/영상이 중간에서 끊기지 않습니다.

## 화질 보존 원칙

핵심 FFmpeg 옵션:

```text
-c copy
```

영상/오디오를 다시 압축하지 않고 기존 압축 스트림을 새 MP4 컨테이너로 연결하므로 **재인코딩에 따른 세대 손실(generation loss)이 없습니다.**

## 메모리 사용 원칙

- Python은 영상 프레임을 디코딩하지 않습니다.
- 대기열 5개를 등록해도 FFmpeg는 항상 1개씩 순차 실행합니다.
- PyAV 같은 프레임 처리 라이브러리를 런타임에 추가하지 않습니다.
- 진행률은 FFmpeg `-progress pipe:1` 출력만 읽습니다.

## FFmpeg

프로그램은 이전 설정, 프로젝트 `bin`, PATH, WinGet Gyan.FFmpeg 설치 폴더 등을 자동 탐색합니다. 못 찾으면 `FFmpeg 설정`에서 `ffmpeg.exe`를 한 번 지정하세요. `ffprobe.exe`는 같은 폴더에 있어야 합니다.
