YouTube Playlist Studio — 친구 테스트판 v0.3
================================================

이 압축파일은 컴퓨터를 잘 모르는 분도 테스트할 수 있게 만든 전용판입니다.
테스트 기능은 딱 2개입니다.

① 영상 늘리기
② 실시간 스트리밍 (24H LIVE)

③ 예약 업로드 / 댓글 관리 / 일본어 도우미는 이 테스트판에서 숨겨져 있습니다.

[처음 한 번]
1. 압축을 완전히 풉니다.
2. "01_처음_한번만_실행.bat"을 더블클릭합니다.
3. FFmpeg가 없으면 Windows의 winget으로 자동 설치를 시도합니다.
4. Windows가 "알 수 없는 게시자"라고 보여주면
   [추가 정보] → [실행]을 누릅니다. (이 테스트 EXE는 코드서명 전 개발판입니다.)

[테스트 1 — 영상 늘리기]
1. 프로그램에서 ① 영상 늘리기를 선택합니다.
2. 같이 들어 있는 TEST_SAMPLE_10SEC.mp4를 추가합니다.
3. 회차 기준을 2회로 지정합니다.
4. 저장 폴더를 확인합니다.
5. [현재 설정을 대기열에 추가] → [대기열 자동 시작]
6. 약 20초짜리 결과 MP4가 만들어지고 정상 재생되는지 봅니다.

[테스트 2 — 실시간 스트리밍]
1. ② 실시간 스트리밍을 엽니다.
2. 처음 테스트는 "내 PC"를 선택합니다.
3. TEST_SAMPLE_10SEC.mp4를 선택합니다.
4. 본인의 YouTube Live Control Room에서 만든 Stream Key를 입력합니다.
5. 처음에는 공개가 아니라 비공개/일부공개 LIVE로 테스트합니다.
6. [24H LIVE 시작] → YouTube에서 영상/소리가 정상인지 확인합니다.
7. 2~3분 확인 후 [LIVE 종료]로 정상 종료되는지 확인합니다.

[Cloud LIVE]
Cloud는 PC LIVE 테스트가 성공한 다음에 진행하세요.
Cloud 연결에는 테스트하는 분 본인의 서버/SSH 키가 필요합니다.
제작자의 서버 주소, SSH 키, Stream Key는 배포판에 들어 있지 않습니다.

[문제가 생기면 제작자에게 보내줄 것]
- 어느 버튼을 눌렀는지
- 화면에 나온 오류 문구 또는 스크린샷
- ① 영상 늘리기 / ② LIVE 중 어디에서 생겼는지
- Windows 10 또는 Windows 11
- 프로그램이 그냥 꺼졌다면 대략 언제 꺼졌는지

중요:
- 압축파일 안에 비밀번호/API Key/YouTube Stream Key/SSH Key는 없습니다.
- Stream Key는 다른 사람에게 보내지 마세요.
- 테스트가 끝나면 YouTube Live Control Room에서 테스트 방송을 종료하세요.
